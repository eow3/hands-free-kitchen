# Hands-Free Kitchen
Control cooking videos with hand gestures, so you never touch your screen with messy hands.

**Live demo:** https://YOUR-USERNAME.github.io/hands-free-kitchen/

| Gesture | Action |
|---|---|
| ✋ Open palm | Play / pause |
| 👍 Thumbs up | Forward 10s |
| 👎 Thumbs down | Back 10s |
| ✌️ Peace sign | 5 min timer |
| ✊ Fist | Stop timer |

All video processing happens in your browser with MediaPipe. No camera frames leave your device.

**Next:** Chrome extension for any YouTube video or recipe blog, and 2DooD integration for shopping lists.
